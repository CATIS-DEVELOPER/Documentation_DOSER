# 📍 Tutoriel : Géolocaliser un Accident avec Précision

**Durée** : 5 minutes | **Niveau** : Débutant | **Outil** : Application Mobile DOSER

---

## 🎯 Objectif

Apprendre à géolocaliser précisément un accident de la route pour faciliter l'analyse des points noirs et l'intervention des secours.

---

## 📋 Prérequis

- ✅ Application DOSER DATA CAPTURE installée
- ✅ GPS activé sur votre smartphone
- ✅ Connexion Internet (pour la carte en ligne) ou cartes hors ligne téléchargées

---

## 📱 Méthode 1 : Géolocalisation Automatique (Recommandée)

### Étape 1 : Activer le GPS

1. Ouvrez l'application DOSER
2. Créez un nouveau constat
3. Dans la section "Localisation", tapez sur **"Activer GPS"**

### Étape 2 : Attendre la Précision Optimale

Le système affiche la précision en temps réel :

- 🔴 **> 50m** : Précision insuffisante (attendre)
- 🟠 **10-50m** : Précision acceptable
- 🟢 **< 10m** : Précision optimale ✓

**💡 Astuce** : Attendez quelques secondes pour atteindre la précision optimale (< 10m).

### Étape 3 : Valider les Coordonnées

1. Vérifiez les coordonnées affichées
2. L'adresse est générée automatiquement
3. Tapez sur **"Confirmer la Position"**

✓ **Résultat** : La position GPS est enregistrée avec une précision < 10m

---

## 🗺️ Méthode 2 : Ajustement Manuel sur Carte

### Quand l'Utiliser ?

- Le GPS n'est pas précis (bâtiments, forêt)
- Vous connaissez l'emplacement exact
- L'accident s'est produit hors de votre position actuelle

### Étapes

1. Tapez sur **"Ajuster sur Carte"**
2. La carte s'affiche avec votre position actuelle
3. **Zoomez** avec les doigts pour voir les détails
4. **Déplacez** le marqueur rouge vers l'emplacement exact
5. **Vérifiez** l'adresse générée
6. Tapez sur **"Confirmer"**

**💡 Astuce** : Utilisez les repères visuels (intersections, panneaux) pour placer précisément le marqueur.

---

## 🏘️ Méthode 3 : Saisie d'Adresse

### Quand l'Utiliser ?

- Pas de GPS disponible
- Accident signalé à distance
- Zone mal couverte par la carte

### Étapes

1. Tapez sur **"Saisir Adresse"**
2. Entrez l'adresse complète :
   - Rue/Route
   - Quartier/Arrondissement
   - Ville
   - Région

3. Tapez sur **"Rechercher"**
4. Le système propose des suggestions
5. Sélectionnez la bonne adresse
6. Les coordonnées GPS sont générées automatiquement

---

## 🎯 Bonnes Pratiques

### ✅ À Faire

1. **Attendre la précision optimale** (< 10m) avant de confirmer
2. **Vérifier l'adresse générée** correspond bien au lieu
3. **Utiliser des repères fixes** (intersection, bâtiment remarquable)
4. **Prendre une photo** du lieu si nécessaire pour confirmation
5. **Noter un point de repère** dans les commentaires ("50m après le rond-point")

### ❌ À Éviter

1. Ne pas confirmer avec une précision > 50m
2. Ne pas se fier uniquement au GPS en zone urbaine dense
3. Ne pas oublier de vérifier l'adresse générée
4. Ne pas géolocaliser depuis le bureau (si l'accident est ailleurs)

---

## 🔧 Résolution de Problèmes

### Le GPS ne trouve pas de position

**Causes possibles** :
- GPS désactivé sur le téléphone
- Pas de vue dégagée du ciel
- Mode avion activé

**Solutions** :
1. Vérifiez que le GPS est activé : Paramètres > Localisation
2. Sortez à l'extérieur ou près d'une fenêtre
3. Désactivez le mode avion
4. Redémarrez l'application

### La précision reste faible (> 50m)

**Solutions** :
1. Attendez 30-60 secondes supplémentaires
2. Déplacez-vous de quelques mètres
3. Utilisez la méthode d'ajustement manuel sur carte
4. Notez la précision dans les commentaires

### L'adresse est incorrecte

**Solutions** :
1. Vérifiez que vous êtes au bon endroit
2. Ajustez manuellement sur la carte
3. Saisissez l'adresse manuellement
4. Ajoutez des précisions dans "Point de repère"

---

## 📊 Cas d'Usage Pratiques

### Accident en Zone Rurale

1. GPS automatique (généralement très précis)
2. Vérifier l'adresse (peut être vague : "Route Nationale 1")
3. Ajouter point de repère : "PK 45 + 200m"
4. Prendre photo du panneau kilométrique

### Accident en Zone Urbaine

1. GPS automatique
2. Ajuster sur carte si précision > 20m
3. Vérifier intersection exacte
4. Noter : "Intersection Rue X et Avenue Y"

### Accident Signalé à Distance

1. Demander l'adresse précise au témoin
2. Saisir l'adresse manuellement
3. Vérifier sur la carte
4. Noter source : "Signalé par témoin au tél : XXX"
