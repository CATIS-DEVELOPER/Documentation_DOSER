# Principes communs des guides rapides DOSER

Ce guide transversal rappelle les bases partagées par tous les utilisateurs DOSER. Chaque guide rapide de rôle s’appuie sur ces fondations ; lisez-les avant de suivre votre procédure spécifique.

## Pré-requis généraux

- Identifiants DOSER actifs (fournis par l’administrateur ou votre hiérarchie).  
- Accès à l’application mobile **DOSER DATA CAPTURE** et/ou au portail web selon votre rôle.  
- Terminal conforme (smartphone Android/iOS ≥ version recommandée, poste Windows 10 64 bits avec Chrome/Firefox/Edge à jour).  
- Connexion Internet stable pour la première synchronisation (le mode hors ligne est ensuite disponible).  
- Autorisations activées sur le terminal : localisation GPS, caméra, stockage.

## Checklist avant toute session

- [ ] Vérifier la disponibilité de votre équipement (batterie, réseau, VPN si requis).  
- [ ] S’assurer que la dernière synchronisation a abouti (icône verte dans l’application / statut « connecté » sur le portail).  
- [ ] Confirmer que les documents ou formulaires nécessaires sont accessibles (modèles, pièces jointes, codes QR).  
- [ ] Connaître les numéros d’urgence et contacts support adaptés à votre rôle.  
- [ ] Préparer les informations critiques attendues (immatriculation, identité, références dossier, etc.).

## Connexion & sécurité

1. **App mobile** : connexion via QR code + identifiants, création d’un code PIN (et biométrie si activée).  
2. **Portail web** : connexion par identifiant / mot de passe, MFA si configurée.  
3. Changer régulièrement votre mot de passe, ne pas le partager.  
4. Verrouiller votre appareil dès que vous quittez votre poste (PIN, badge, écran verrouillé).  
5. En cas de perte/vol, prévenir immédiatement l’administrateur pour révoquer l’accès.

## Synchronisation & mode hors ligne

- L’application mobile fonctionne **offline-first** : les données restent stockées localement jusqu’à la prochaine connexion.  
- Icônes d’état : 🟢 connecté, 🟠 données en attente, 🔴 erreur de synchronisation.  
- Forcer une synchronisation : **Menu > Paramètres > Synchroniser maintenant** (app) ou **Bouton synchroniser** (portail).  
- En cas d’erreur persistante, contacter le support et noter le message affiché.

## Bonnes pratiques de collecte

- Travailler en suivant les formulaires dans l’ordre pour limiter les oublis.  
- Utiliser les contrôles de complétude intégrés (barres de progression, messages) avant validation.  
- Joindre un minimum de preuves : photos horodatées, croquis, pièces justificatives.  
- Vérifier systématiquement la géolocalisation et corriger si besoin.  
- Consigner les retours terrain (anomalies, difficultés) pour amélioration continue.
