## 📱 Application Mobile DOSER DATA CAPTURE

L'application mobile est l'outil essentiel au cœur du système de collecte de données DOSER.

### Fonctionnalités Clés

- ✅ **Mode hors ligne** : Travaillez sans connexion Internet
- ✅ **Synchronisation intelligente** : Envoi automatique dès que le réseau est disponible
- ✅ **Interface intuitive** : Navigation simple et guidée
- ✅ **Capture multimédia** : Photos, vidéos, audio
- ✅ **Géolocalisation automatique** : Position GPS précise
- ✅ **Validation en temps réel** : Contrôles de cohérence immédiats
- ✅ **Sécurité renforcée** : Code PIN, chiffrement, contrôle d'accès

### Connexion et Sécurité

- **Connexion rapide** : Scan de code QR ou saisie manuelle
- **Mémorisation** : Les informations de connexion sont sauvegardées
- **Code PIN** : Protection par code à 4 chiffres
- **Multi-comptes** : Gestion de plusieurs comptes sur un même appareil
- **Sécurité RBAC** : Accès basé sur les rôles
